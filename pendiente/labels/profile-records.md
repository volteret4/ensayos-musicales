# label - Profile Records

## curiosities
**Run DMC's Success** : Profile Records experienced significant success with Run DMC's debut album, which achieved gold certification within nine months of its 1984 release, selling half a million copies. The label continued to release Run DMC's subsequent albums, including the sophomore "King of Rock" and the breakthrough "Raising Hell," and strategically issued "Walk This Way" as a single in the summer of 1986.
