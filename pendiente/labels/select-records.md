# label - Select Records

## curiosities
**Success with "Roxanne Roxanne" (1985)** : The independent label Select Records achieved significant success when UTFO's "Roxanne Roxanne" cracked the top 10 on Billboard's R&B chart in March 1985. This was considered "remarkable for a rap single by a new group on the Independence Select Records label," highlighting the label's early impact in the burgeoning rap scene.
