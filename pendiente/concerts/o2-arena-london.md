# concert - O2 Arena (London)

## curiosities
**Christine McVie's Return to Stage** : After staying off stage for all of the 2000s, Christine McVie was finally persuaded to return to the stage for a single, much-touted appearance at London's O2 Arena in 2013. This event was described as a "breakthrough" for her, leading to her rejoining Fleetwood Mac for extensive touring.
