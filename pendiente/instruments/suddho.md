# instrument - Suddho

## curiosities
**Heavy Brazilian Drum** : The Suddho is described as a heavy Brazilian drum. Phil Collins played this instrument on Peter Gabriel's 1980 track "Biko," which was Gabriel's eulogy for South African anti-apartheid activist Stephen Biko, adding a distinctive percussive element to the song.
