# instrument - Boss DR55 drum machine

## curiosities
**Joe Jackson's Key Tool** : Joe Jackson programmed a Boss DR55 drum machine in his small SoHo studio, using it as a key instrument for his album "Night and Day." This drum machine contributed to the electronic soundscapes of the album, especially for tracks like "Steppin' Out."
